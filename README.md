# Web Development Projects Using HTML and CSS

## Project Overview

This project contains three simple websites developed using basic HTML and CSS. The main aim is to create attractive, user-friendly web pages with easy navigation, clear layouts, and organized information.

## Project 1: Doctor Appointment Booking Website

### Aim
To design a doctor appointment booking website using basic HTML and CSS.

### Description
Create a website that displays doctor profiles, medical specializations, consultation timings, available appointment slots, and patient registration details.

### Features
- Doctor profiles with names and photos
- Medical specializations
- Consultation timings
- Available appointment slots
- Patient registration form
- Clear form labels
- Simple navigation menu
- Book Appointment button

### Technologies Used
- HTML for website structure
- CSS for styling and layout

---

## Project 2: Student Dashboard Website

### Aim
To create a student dashboard displaying academic information using basic HTML and CSS.

### Description
Design a student dashboard that helps students view their personal information, academic performance, attendance, examination schedules, and college announcements.

### Features
- Student profile and personal details
- Sidebar navigation menu
- Semester examination results
- Attendance percentage with progress bars
- Subject information
- Examination timetable
- College announcements
- Information cards and tables

### Technologies Used
- HTML for dashboard structure
- CSS for sidebar, tables, cards, and progress bars

---

## Project 3: Online Food Ordering Website

### Aim
To design an attractive online food ordering website using basic HTML and CSS.

### Description
Create a food ordering interface that displays restaurant details, menu categories, food images, prices, special offers, and customer reviews.

### Features
- Restaurant name and details
- Food menu categories
- Food images and descriptions
- Food prices
- Special discounts and offers
- Customer ratings and reviews
- Order Now buttons
- Attractive background colors
- Mobile-friendly navigation
- Food cards with CSS styling

### Technologies Used
- HTML for website structure
- CSS for colors, backgrounds, cards, and responsive design

---

## Software Requirements

- Visual Studio Code or Notepad
- Google Chrome or any web browser
- Windows, Linux, or macOS

## How to Run the Projects

1. Open Visual Studio Code.
2. Create a new folder for each project.
3. Create a file named `index.html`.
4. Write the HTML code and include CSS inside the `<style>` tag.
5. Save the file.
6. Open `index.html` in a web browser.
7. View the website output.

## Project Objectives

- Understand the basics of HTML and CSS.
- Learn to create web page layouts.
- Design forms, tables, cards, and navigation menus.
- Improve website appearance using CSS.
- Develop simple and responsive user interfaces.

## Conclusion

These three projects demonstrate how basic HTML and CSS can be used to create useful and attractive websites. They help beginners understand web page design, styling, navigation, forms, and responsive layouts.

**Note:** These are front-end demonstration projects. Functional appointment booking, student data management, and food order processing require additional programming and backend integration.
